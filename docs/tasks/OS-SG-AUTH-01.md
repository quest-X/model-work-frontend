## 目标与当前基础

在OpenSight个人设置导出授权文件，Sigine直接导入，联用本人获准的模型资源和生产辅助能力，减少重复登录。“全部”覆盖目标保留；必须同时满足当前账户权限、群/节点/项目范围、资源可用性及原审批。

- [个人中心](../../src/views/AccountCenter/AccountCenter.tsx)及[账户服务](../../src/services/AccountService.ts)已有资料、会话、权限和范围。
- [账户签名](../../../model-work-node/model_work_node/accounts.py)针对具体节点/操作/参数与短时有效期，不能充当长期通用凭据。
- Node Harness源码登记8个工具，并非全部生产能力目录；视觉检索、标注、摄像头、生产程序等须逐项列适配/未覆盖范围。
- Sigine的[desktop-quota.mjs](../../../../01-Sigine/model-work-sigine/desktop-quota.mjs)已有8小时、可撤销的desktop:model:test令牌，仅覆盖所属用户部分personal_connections模型；其结果不代表全部订阅/共享模型可调用。

## 共同契约草案

协议名沿用Sigine承接方提出的`opensight-sigine-grant.v1`。以下均为待实现约定。

1. 签名载荷包含：`schema_version`、`grant_id`、`issuer`(实例及key_id)、`subject`(OpenSight账户/审批身份/安装实例)、`audience`(目标Sigine实例及用户)、明确`capabilities`和`scopes`(groups/nodes/projects)、`issued_at`、`expires_at`、`nonce`。签名覆盖完整载荷；专用服务端签发密钥及轮换规则与逐操作审批密钥分开，编码/算法和跨语言测试向量在实现前锁版。
2. 导出范围由服务器展开当前可授权能力和资源ID；新增能力不自动扩权。文件不含密码、私钥、Provider密钥或长期bearer token；文件本身不能直接执行生产操作。
3. Sigine复用当前登录态，验证可信预登记签发者、签名、目标主体/实例、时间与在线撤销状态，再向可信OpenSight服务登记/换取受限连接凭据。不能信任文件自带公钥或任意URL，也不能按同邮箱自动建立身份关联。首次绑定须双方账户所有者确认；绑定后的文件只能供指定Sigine用户使用。
4. Sigine仅在受保护服务端存储或桌面钥匙串保存兑换凭据。重复导入按grant_id幂等，不续期或扩大范围。每次调用复核OpenSight实时权限和Sigine自身模型归属、渠道、额度；原敏感操作仍需逐次审批，不能代签或跳过。
5. 撤销、停用、权限收缩和密钥失效阻止后续新调用；在途操作沿既有取消/停止机制，不承诺自动回滚。审计关联两端用户、grant_id、request_id、能力/资源、审批和用量，不记录秘密。

建议新增接口族：OpenSight `/core_service/account/delegations`负责签发/列表/撤销，并提供受保护的兑换/内省接口；Sigine `/api/platform/delegations/import`负责导入，配套列表/解除关联。接口路径、签名编码及错误码尚未锁版，不是现有可调用API。

实现前还需锁定grant_id首次兑换、重复导入及凭据轮换边界，以及可信公钥分发与跨语言签名测试向量。两端已核对协议名与权限边界，线协议及联调仍未完成。

候选核心：Node 仓库 `model_work_node/opensight_sigine_grant.py` 可用调用方提供的专用 Ed25519 私钥签发规范 JSON；Sigine `opensight-grant.mjs` 用预登记公钥、受众和时限校验。合成向量的 Python 3 项与 Node 4 项测试通过。尚未配置真实签名密钥，未接入账户签发、撤销、首次绑定或能力调用；7 天只是代码当前上限，不代表用户已接受默认期限。

## 实施与验收

先锁定主体绑定和协议，再做OpenSight个人中心/签发撤销及Sigine导入/资源适配，最后联调。建立完整能力清单及模型来源矩阵；未接入项明确展示，不把8个工具或桌面测试接口当作全部覆盖。

验收覆盖：本人模型与能力真实调用；跨用户/群/节点/项目及错实例拒绝；篡改/过期/撤销/重放/重复导入；角色降权、账户停用、密钥轮换；离线/超时；额度不足、审批拒绝、重启恢复与审计关联。源码、模拟测试、真实模型调用和生产验收分别记录。

## 待用户确认

- 首次关联：推荐复用双端登录态一次确认后导出；也可先导出，但首次激活必须由OpenSight本人确认绑定。不能仅凭持有文件绑定任意Sigine账户。
