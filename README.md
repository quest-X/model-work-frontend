# OpenSight

<p align="center"><strong>中文</strong> | <a href="README_EN.md">English</a></p>

面向视觉数据的智能标注平台，支持从数据整理、辅助标注到模型验证的一体化工作流。

![OpenSight 平台预览](docs/preview.png)

## 主要能力

- 图片与视频标注
- 目标检测、实例分割与视频跟踪
- 数据集、批量推理与训练任务管理
- 相似图像检索与模型分析
- 计算资源与工作节点管理
- 常用标注格式导入与导出

## 快速开始

```bash
git clone https://github.com/quest-X/model-work-frontend.git
cd model-work-frontend
npm install
npm start
```

开发命令：

```bash
npm run build
npm test
npm run lint
```
